### About

Hi, I'm ItzCritsLow, the developer behind StudioFDX. I design and build for the web and beyond: fast websites, online stores that convert, and custom software shaped around what a project actually needs. On the side I develop Minecraft Fabric mods, which is where a lot of my Java experience comes from.

I care about clean, maintainable code and interfaces that feel effortless to use. Whether it is a landing page, a full web shop, or a custom tool, I like shipping things that look sharp and run well.

### What StudioFDX does

- **Websites:** modern, responsive and fast, built to fit your brand.
- **Online stores:** complete web shops with a smooth checkout and an easy to manage catalog.
- **Custom software:** tailored tools, dashboards and systems for specific needs.
- **Minecraft development:** client side mods and utilities built with Fabric.

### Currently building

Right now I'm building a brand new web shop. You can follow the progress on [studiofdx.nl](https://studiofdx.nl).
